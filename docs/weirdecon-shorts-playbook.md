# 이상한 경제사전(@weirdecon) — 조회수 플레이북

"업로드 48시간 뒤 영상이 죽는 이유 · 5가지만 수정하세요" 영상의 조언을
**쇼츠 채널인 이 채널에 맞게 다시 판정하고 재작성한 것.**

원본 영상은 **롱폼(가로 10분+) 기준**이다. 5+5 중 절반은 쇼츠에 존재하지 않는
기능을 쓰라고 한다. 그대로 따라 하면 시간만 쓰고 지표는 안 움직인다.

---

## 0. 먼저 — 원본 5가지 판정표 (업로드 후 편)

| # | 원본 조언 | 쇼츠 적용 | 이유 / 대체안 |
|---|---|---|---|
| 1 | 챕터(타임스탬프) 3개 이상 | ❌ **불가** | 쇼츠 플레이어에 챕터 UI가 없다. 설명문에 `00:00`을 써도 표시되지 않는다. → **대체: 설명문 첫 두 줄 키워드**(검색 색인은 여전히 유효) |
| 2 | 전용 재생목록 + 키워드 설명 | ⚠️ **부분 유효** | 쇼츠도 재생목록에 담을 수 있고 재생목록 제목·설명은 색인된다. 다만 재생목록 연속재생이 쇼츠 피드에서는 작동하지 않는다. → **채널 홈 섹션 정리 용도로만** |
| 3 | 인기 영상 엔딩화면에 연결 | ❌ **불가** | 쇼츠에는 엔드스크린·카드 자체가 없다. → **대체: 마지막 세그먼트의 "다음 편 예고"**(스킬 4단계에 이미 있음) + 고정 댓글 링크 |
| 4 | 키워드 유도 고정 댓글 | ⚠️ **목적을 바꿔서 유효** | 쇼츠에서 댓글은 SEO보다 **참여 신호**다. 키워드 낚시 대신 **반론 한 줄**을 고정한다 (아래 3-③) |
| 5 | 스튜디오 편집기로 앞부분 잘라내기 | ❌ **사실상 무의미** | 앞을 잘라도 이미 쌓인 성과 이력은 초기화되지 않는다. 노출이 이미 멎은 영상은 되살아나지 않는다. → **대체: 재업로드**(아래 5번). 쇼츠에서는 이게 유일하게 작동하는 수단이다 |

**그리고 전제 자체가 다르다.** "48시간 뒤 죽는다"는 롱폼 이야기다.
쇼츠는 업로드 2~4주 뒤에 다시 노출이 붙는 경우가 드물지 않다.
**T+48h에 영상을 사망 판정하지 말 것.** 판정 시점은 아래 6번 타임라인을 따른다.

## 1. 이 채널이 볼 지표는 CTR이 아니다

원본 영상의 "클릭률 5% 이하면 썸네일 교체"는 쇼츠에 적용되지 않는다.
쇼츠 피드는 자동재생이라 클릭이라는 행동이 없다.

유튜브 스튜디오 → 해당 쇼츠 → 도달범위/참여도에서 **세 개만** 본다.

| 지표 | 합격선 | 미달일 때 범인 |
|---|---|---|
| **조회 vs 넘김** (viewed / swiped away) | 70%+ | **첫 3초**. 훅 실패. 대본이 아니라 오프닝 한 컷 문제 |
| **평균 조회율(%)** | 65%+ (60초 기준) | **20~35초 구간**. 반전이 늦거나 설명이 길다 |
| **재시청 / 좋아요·댓글** | 좋아요 3%+ | 결론이 안 남았다. `emph` 대형 자막이 약하다 |

- **조회 vs 넘김만 낮다** → 오프닝만 갈아서 재업로드. 대본은 건드리지 않는다.
- **평균 조회율만 낮다** → 대본 구조 수정. 재업로드해도 같은 곳에서 또 빠진다.
- **둘 다 높은데 조회수가 안 늘었다** → 영상 문제가 아니다. 소재 수요가 없다. 그 용어는 버린다.

> 반전형(R) 포맷 주의: **반전은 20~25초 안에 나와야 한다.**
> 60초 영상에서 반전이 40초에 있으면 평균 조회율이 구조적으로 50%를 못 넘는다.

## 2. 이 채널의 진짜 병목 (원본 영상이 다루지 않는 것)

원본의 "죽은 영상 심폐소생 5가지"는 **이미 조회수 기반이 있는 채널**을 전제한다.
편수가 한 자릿수인 채널의 병목은 개별 영상 최적화가 아니라 **표본 부족**이다.

- 편수 10편 미만 구간에서는 **살리기보다 쌓기가 우선.**
  한 편을 세 번 손보는 시간에 새 편을 만드는 쪽이 기대값이 높다.
- 이 구간에서 유효한 최적화는 딱 두 개: **첫 3초 훅**과 **재업로드 판정**.
  나머지(재생목록, 고정 댓글, 설명문 SEO)는 편수가 붙은 뒤에 몰아서 한다.
- 원본이 말한 "충성 시청자 중심 소비에 그친다"는 문제는 이 채널엔 아직 해당 없다.
  구독자 기반이 없으니 애초에 전부 신규 노출이다. **다른 병을 치료하지 말 것.**

**시리즈 훅이 이 채널의 가장 강한 무기다.**
스킬 4단계가 이미 마지막 세그먼트에 "다음 편 예고"를 넣게 되어 있다.
이걸 반쪽으로 쓰고 있다 — 다음 편의 **첫 3초에서 그 예고를 회수**해야 짝이 완성된다.

```
N화 마지막:   "그럼 왜 하필 '곰'이었을까요? 다음 편에서."
N+1화 첫 3초: "곰이었던 이유, 지금 말합니다."   ← 이 한 줄이 없으면 예고는 버려진다
```

## 3. 업로드 후 — 이 채널에서 실제로 할 5가지

### ① 제목 교체 (썸네일보다 이것부터)
쇼츠 피드에는 썸네일이 안 뜨지만, **검색·채널 탭·관련 영상에는 뜬다.**
제목은 공개 후에도 교체할 수 있고 검색 색인이 갱신된다.

- 정의형 ❌ → 질문·모순형 ⭕
  - `체리피커란 무엇인가` → `은행이 제일 싫어하는 손님`
  - `블랙스완 뜻` → `아무도 못 맞힌 게 아니라, 안 본 겁니다`
- 용어 자체는 **제목 안에 반드시 남긴다** (검색 유입 경로). 부제 형태로라도.

### ② 설명문 첫 두 줄
챕터 대신 여기가 색인 지점이다. 첫 두 줄 안에 **용어 + 용어의 오해**를 넣는다.
해시태그는 3개 이하. `#쇼츠 #shorts` 남발은 아무 도움이 안 된다.

### ③ 고정 댓글 — 낚시 대신 반론
이 채널의 차별점은 스킬 1단계의 **7번 항목(반론)** 과 `note`(원저작 해설)다.
고정 댓글을 그 연장으로 쓴다. 참여도 신호와 비정품 정책 방어선을 동시에 챙긴다.

```
이 용어, 사실 경제학 교과서엔 안 나옵니다.
그럼 어디서 왔을까요 — 출처는 (   ), 그런데 여기에도 반론이 있습니다. ↓
```

### ④ 재생목록 / 채널 홈 섹션 (편수 10편 넘은 뒤에)
`시장이 고장 나는 방식` / `이름이 이상한 이유` / `사람이 비합리적일 때` 정도로
3~4개. 재생목록 **설명문에 키워드를 쓴다** — 여기는 색인된다.
편수가 적을 때 만들면 빈 껍데기라 오히려 채널이 비어 보인다.

### ⑤ 재업로드 (앞부분 잘라내기의 쇼츠판 대체)
아래 5번 규칙에 걸리면 **편집이 아니라 재업로드**한다.

## 4. 업로드 전 — 기획 5단계 (스킬 순서 변경 포함)

### ① 아이디어 검증 — 해결책이 아니라 문제 제기
이 채널은 구조상 이미 합격이다 ("왜 이런 이상한 이름이 붙었나").
검증할 것은 하나: **그 용어를 검색하는 사람이 실제로 있는가.**
학계에서만 쓰는 용어는 리스크 등급과 별개로 **수요가 0일 수 있다.**

### ② 포장지 먼저 — ⚠️ 스킬 순서를 바꿔야 한다
현재 스킬은 **제목·설명문을 8단계(마지막)** 에 만든다. 이게 원본 영상이 지적한
"포장지를 나중에 만드는" 실수 그대로다.

**변경 제안:**
```
현재: 조사 → 대본 → 검수 → 장면분해 → 이미지 → TTS → 조립 → 제목/설명문
변경: 조사 → [제목 + 첫 3초 훅 + 엔드카드 문구 확정] → 대본 → 검수 → … → 설명문
```
제목과 첫 3초를 먼저 못 쓰겠으면, **그 편은 만들지 않는다.**
이게 가장 싼 손절 지점이다 — 이미지 생성과 TTS를 태우기 전에 걸러진다.

### ③ 대본 — 인사말 생략은 이미 지키고 있다
바꿀 것은 키워드 위치다. 원본은 "30초 내"라고 했지만 **쇼츠는 3초 내**다.

- 음성 첫 문장에 용어를 넣는다.
- **번인 자막에도 넣는다.** 화면 텍스트도 색인 대상이다. 첫 컷 `emph`에 용어를 노출.
- 스킬의 `emph`는 "시각적 대조"로 쓰라고 되어 있는데, **첫 컷만 예외로 용어 노출**을 겸한다.

### ④ SEO / 업로드
화·목·토 19시 유지. 다만 **쇼츠는 롱폼보다 업로드 시각 민감도가 낮다** —
피드 노출이 며칠에 걸쳐 분산되므로 시각 최적화에 시간을 쓰지 말 것.
`변경된 콘텐츠 또는 합성 콘텐츠 → 예` 체크는 매 편 그대로.

### ⑤ 사후 피드백 — 48시간이 아니라 4개 체크포인트

## 5. 재업로드 판정 규칙

| 조건 | 조치 |
|---|---|
| 조회 vs 넘김 < 50% | **오프닝만 교체 후 재업로드.** 대본·이미지 재사용, `--skip-tts`로 빠르게 |
| 조회 vs 넘김 ≥ 65% + 평균 조회율 < 50% | 재업로드 금지. **대본 구조 수정** 후 다음 편에 반영 |
| 둘 다 합격 + T+7d 조회수 500 미만 | 소재 수요 없음. **버린다.** 30화 목록에서 유사 용어도 같이 뺀다 |
| T+30d 조회수가 여전히 상승 중 | 건드리지 않는다. 쇼츠는 뒤늦게 붙는다 |

**재업로드 시 지킬 것**
- 원본을 **비공개로 내리고** 올린다. 두 개를 동시에 공개해 두지 않는다.
- 훅·제목을 **실제로 바꾼다.** 동일 파일 재업로드는 중복 취급 위험이 있고, 무엇보다
  같은 영상은 같은 결과가 나온다.
- **한 편당 재업로드는 1회까지.** 두 번째로 실패하면 소재 문제다.

## 6. 체크포인트 타임라인

| 시점 | 볼 것 | 조치 |
|---|---|---|
| **T+1h** | 조회 vs 넘김 | 아무것도 하지 않는다. 표본 부족. 기록만 |
| **T+24h** | 조회 vs 넘김, 평균 조회율 | 제목·설명문·고정 댓글 정비 (3-①②③) |
| **T+7d** | 조회수, 평균 조회율 | **재업로드 판정** (5번 표) |
| **T+30d** | 조회수 추세 | 상승 중이면 방치. 멎었으면 30화 목록에서 유사 소재 재조정 |

## 7. 복붙용 프롬프트

### A. 편별 사후 진단 (T+24h / T+7d)

```
이상한 경제사전(@weirdecon) 쇼츠 채널의 한 편을 진단해줘.
docs/weirdecon-shorts-playbook.md 의 기준을 그대로 적용할 것.

[회차]        N화 / 용어: (       ) / 포맷: (Q/R/C) / 길이: (   )초
[제목]        (현재 제목 그대로)
[첫 3초 대사] (음성 첫 문장 + 첫 컷 emph 자막)
[반전 시점]   (R 포맷이면 반전이 몇 초에 나오는지)
[지표]        조회 vs 넘김 (  )% / 평균 조회율 (  )% / 조회수 (  ) / 좋아요 (  )
[경과]        T+(  )

다음 순서로만 답해라. 일반론 금지, 이 편에 대해서만.
1. 세 지표 중 어디가 깨졌는지 하나로 특정 (첫 3초 / 중반 구조 / 소재 수요)
2. 플레이북 5번 표에 따른 판정: 재업로드 / 대본수정 / 소재폐기 / 방치
3. 재업로드 판정이면 → 새 첫 3초 대사 3안 + 첫 컷 emph(16자 이하) 3안
4. 대본수정 판정이면 → 몇 초 지점을 어떻게 줄일지 구체적으로
5. 제목 교체안 3개 (질문·모순형, 용어는 반드시 포함)
6. 고정 댓글 1개 (키워드 낚시 금지, 반론 한 줄 형식)
7. 이번 진단에서 다음 편에 넘길 교훈 1줄
```

### B. 편별 사전 기획 (촬영=이미지 생성 전에 반드시)

```
이상한 경제사전 N화를 만들기 전에 포장지부터 확정하자.
용어: (       )

대본을 쓰기 전에 아래를 먼저 내라. 하나라도 안 나오면 이 편은 접는다.
1. 제목 3안 — 질문·모순형, 용어 포함, 20자 이하
2. 첫 3초 대사 1문장 — 용어가 첫 문장에 들어갈 것, 인사말 금지
3. 첫 컷 emph 자막 — 16자 이하, 여기엔 용어를 노출 (다른 컷은 시각적 대조로)
4. 반전 시점 — 몇 초에 무엇이 뒤집히는지 한 줄 (R 포맷이면 25초 이내)
5. 엔드카드 문구 + 다음 편 예고 1줄
6. 직전 편 예고를 이 편 첫 3초에서 회수하는 문장 (직전 편 예고: "     ")
7. 이 용어를 실제로 검색할 사람이 있는지 — 있다/없다 + 근거 1줄
   '없다'면 여기서 중단하고 대체 용어 3개를 제안할 것

그 다음에야 스킬의 1단계(조사)로 들어간다.
```

## 8. 그대로 유지할 것 (건드리지 말 것)

- **원저작 해설 `note` 매 편 1개 이상** — 조회수 최적화보다 우선한다. 비정품 정책 방어선
- **지방재정·행정·의회 소재 금지** — 겸직 심사 직무관련성
- **협찬·광고·상품 언급 금지**
