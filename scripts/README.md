# 온비드 세컨하우스 후보 검색기

`scripts/onbid-secondhouse.mjs` — 온비드(한국자산관리공사) 공매 물건 중
**최저입찰가 6천만원 이하 · 단독/농가주택 · 수도권에서 차로 2시간권** 물건을 뽑아
CSV로 저장하는 무의존성 Node 스크립트다.

데이터 출처는 공공데이터포털에 공개된 캠코 공식 OpenAPI 두 건이며, 블로그·중개 사이트는 쓰지 않는다.

| 서비스 | 공공데이터포털 |
| --- | --- |
| 한국자산관리공사_온비드 캠코공매물건 조회서비스 | https://www.data.go.kr/data/15000851/openapi.do |
| 한국자산관리공사_온비드 이용기관 공매물건 조회서비스 | https://www.data.go.kr/data/15000849/openapi.do |

## 1. 준비

**① 인증키 발급** (무료, 대부분 즉시 승인)
위 두 서비스 페이지에서 "활용신청" → 마이페이지에서 **일반 인증키(Decoding)** 복사.

**② 네트워크 허용**
호출 대상 도메인은 `openapi.onbid.co.kr` 이다. 사내망·에이전트 환경에서는
`openapi.onbid.co.kr`, `www.onbid.co.kr`, `apis.data.go.kr`, `www.data.go.kr` 를 아웃바운드 허용 목록에 넣어야 한다.
(Claude Code 웹 세션이라면 환경 설정의 네트워크 정책에 위 도메인을 추가)

## 2. 실행

```bash
export ONBID_SERVICE_KEY='발급받은_디코딩_키'

# 기본: 6천만원 이하 · 단독/농가주택 · 수도권 2시간권
node scripts/onbid-secondhouse.mjs

# 상한·범위 조정
node scripts/onbid-secondhouse.mjs --max-price 80000000 --pages 30 --json

# 전국·전 유형으로 넓게 훑기
node scripts/onbid-secondhouse.mjs --all-regions --include-all
```

결과는 기본 `out/onbid-secondhouse.csv` (엑셀 한글용 BOM 포함) + 콘솔 상위 20건.
정렬은 **감정가 대비 최저입찰가 비율이 낮은 순** → 같으면 최저입찰가 낮은 순이다.
유찰이 쌓여 값이 빠진 물건이 위로 올라온다.

### 옵션

| 옵션 | 설명 |
| --- | --- |
| `--key <키>` | 인증키 (없으면 `ONBID_SERVICE_KEY`) |
| `--max-price <원>` | 최저입찰가 상한, 기본 `60000000` |
| `--pages <N>` / `--rows <N>` | 서비스별 최대 페이지 / 페이지당 건수 (기본 10 × 100) |
| `--service kamco\|usage\|both` | 조회 대상 서비스, 기본 `both` |
| `--all-regions` / `--include-all` | 지역 / 유형 필터 해제 |
| `--out <경로>` / `--json` | 출력 경로, JSON 동시 저장 |
| `--raw` | 첫 페이지 원본 XML 덤프 (응답 필드명 확인용) |
| `--fixture <경로>` | 네트워크 대신 로컬 XML로 실행 (오프라인 검증용) |

## 3. 응답 필드가 안 맞을 때

캠코 API는 서비스·개편 버전에 따라 응답 태그명이 다르다. 스크립트는
`MIN_BID_PRC`, `APSL_ASES_AVG_AMT`, `LDNM_ADRS` 등 **후보 이름 목록**으로 관대하게 매핑한다.
값이 비어 나오면 원본을 먼저 확인하고 `FIELD_ALIASES` 에 실제 태그명을 추가하면 된다.

```bash
node scripts/onbid-secondhouse.mjs --raw --service kamco | head -60
```

엔드포인트 경로도 포털의 "요청주소"와 다르면 파일 상단 `SERVICES` 만 고치면 된다.

## 4. 필터 기준과 한계

- **수도권 2시간권**: 서울 도심 출발 승용차 기준으로 경기 전역, 인천(강화·옹진), 강원 영서(춘천·홍천·원주·횡성 등),
  충북 북부(충주·제천·음성·진천 등), 충남 북부(천안·아산·당진·예산·홍성 등)를 포함하고
  제주·영남·호남·영동은 제외했다. 소재지 문자열 기반이라 **실제 소요시간은 물건별로 다시 확인해야 한다.**
- **주택 유형**: 단독주택·다가구·농가주택·전원주택·별장을 우선하고 아파트·다세대·상가·토지 단독 물건은 뺀다.
- **가격**: 감정가가 아니라 해당 회차 **최저입찰가** 기준이다. 유찰되면 회차마다 낮아지므로 목록은 조회 시점의 스냅숏이다.

## 5. 입찰 전 반드시 직접 확인할 것

공매 물건은 목록 정보만으로 판단할 수 없다.

- 압류재산은 **명도 책임이 매수인**에게 있고 점유자·임차인 문제가 남을 수 있다
- 등기부등본상 인수되는 권리(선순위 임차권, 법정지상권, 유치권 주장 등)
- 농가주택은 **농지·농막 여부, 진입도로(맹지), 상하수도·정화조** 확인 필요
- 무허가·미등기 건물이 지상에 있는지, 건축물대장과 현황이 맞는지
- 세컨하우스는 1세대 2주택 판정 및 취득세·종부세 영향 확인 (농어촌주택 특례 요건 별도)

물건 상세·공고문·현황조사서는 온비드(https://www.onbid.co.kr) 물건 상세 화면에서 볼 수 있다.
