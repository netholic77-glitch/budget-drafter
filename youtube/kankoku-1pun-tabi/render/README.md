# 렌더 파이프라인 — 애니매틱 자동 생성

`script.md`의 초 단위 콘티와 `subtitles.ja.srt`를 입력으로 받아
**1080×1920 / 30fps / 60초 MP4**를 통째로 만들어 내는 파이프라인입니다.
외부 이미지를 단 한 장도 쓰지 않습니다 — 배경은 전부 코드가 그립니다.

## 지금 만들어지는 것 / 아직 아닌 것

| | 상태 |
|---|---|
| 화면 구성·컷 분할·켄번즈·하드컷 | **완성** — 본편 그대로 |
| 일본어 자막 번인 (숫자 줄바꿈 보호 포함) | **완성** |
| 종이인형 ハンちゃん 스냅 애니메이션 | **완성** |
| 나레이션 음성 | **가이드 보이스** — Open JTalk(오프라인). 본편은 성우 또는 상용 TTS로 교체 |
| 배경 | **종이 오려붙이기 자동 생성** — 본편은 공공누리 제1유형 실사로 교체 |

각 컷 하단에 `本番実写：…` 로 **어떤 실사가 그 자리에 들어가야 하는지** 표기됩니다.
실사 확보 조건은 `../assets-guide.md` 참조.

> 「종이인형이 없는 컷은 업로드하지 않는다」(`../format-spec.md`) 는 이 파이프라인이 구조적으로 보장합니다.
> 캐릭터 레이어는 모든 프레임에 무조건 합성됩니다.

## 실행

```bash
# 1회만 — 시스템 의존성
apt-get update && apt-get install -y ffmpeg fonts-noto-cjk \
    open-jtalk open-jtalk-mecab-naist-jdic hts-voice-nitech-jp-atr503-m001
pip3 install pillow numpy

# 에피소드 렌더 (audio → video 순서)
python3 build_audio.py ep01 audio_ep01.wav
python3 render.py     ep01 out_ep01.mp4 audio_ep01.wav
```

`ep01` 자리에 `ep02`(仏国寺) · `ep03`(水原華城). 1편당 약 80초 소요.

## 파일

| 파일 | 역할 |
|---|---|
| `paperart.py` | 공용 작화 프리미티브(기와지붕·능선·소나무) + EP.01 장면 12종 + 캐릭터 리그 |
| `scenes_ext.py` | EP.02·03 장면 21종 |
| `ep01.py` `ep02.py` `ep03.py` | 컷 타임라인 + TTS 원고. **대본을 고치면 여기만 고친다** |
| `build_audio.py` | 나레이션 합성 → 컷 길이에 맞춰 낭독 속도 자동 조정 → 종이 넘김 효과음·패드 믹스 |
| `render.py` | 프레임 합성 → ffmpeg 파이프 → H.264 + AAC |

## 캐릭터 리그 (`hanchan`)

- 6피스 컷아웃. 팔은 어깨 피벗 회전만 — **트위닝 없음, 3프레임 스냅**
- `outfit`: `hanbok`(왕궁) / `gat`(사찰) / `dopo`(성곽) — 편마다 소품만 교체, 제작비 0
- 그림자 고정: `opacity 25% / blur 8px / y+12px`

## 알려진 한계

- Open JTalk 음성은 남성 1종(nitech-jp-atr503-m001)뿐이고 억양이 기계적입니다. 실제 업로드 전 교체 필요.
- 고유명사(金大城·丁若鏞 등)는 한자 그대로 두면 오독하므로 타임라인의 `NARRATION`에 **가나로 풀어 적어** 두었습니다. 화면 자막은 한자 그대로입니다.
- 완성본 MP4는 1편당 25~28MB이며 저장소에 커밋하지 않습니다. 위 명령으로 언제든 재생성됩니다.
