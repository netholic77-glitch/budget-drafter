## 한 줄 요약

**韓国だけ。60秒だけ。二度目の韓国のための場所案内。**
서울 쇼핑·먹방이 아니라 **재방문자(再訪組)를 위한 유적·사찰·소도시 명소**를,
얼굴 없는 **종이인형 캐릭터 + 공공누리 실사**로 60초에 담는다. 한일 비교는 하지 않는다.

## 포맷 규격

- 해상도 1080×1920 (9:16), 길이 **60초 이내**, 30fps
- 나레이션: 일본어(약 300자) / 자막: 일본어 번인 + 자동자막용 SRT 동시 제공
- **모든 컷에 종이인형 캐릭터 「ハンちゃん」 필수** — 유튜브 「재사용된 콘텐츠」 판정을 피하는 장치
- 40~52초 실무정보(요금·시간·휴무) 구간 생략 금지
- 업로드: 주 3회 (화·목·토) 21:00 JST — 일본 시청자 프라임타임

## 절대 하지 않는 것

- 네이버·구글 이미지 검색 결과 사용 (저작권 침해 + 수익창출 거절 위험)
- 한국과 일본 비교
- 개인 블로그·커뮤니티를 사실 근거로 사용

## 남은 작업 (사용자 확인 필요)

이 세션에는 YouTube API/MCP 연결이 없어 **채널명 변경과 영상 업로드는 자동으로 수행할 수 없습니다.**
아래 두 가지 중 하나를 알려주시면 이어서 진행합니다.

1. YouTube Data API 자격증명을 연결해 주시면 업로드까지 자동화
2. 직접 업로드 — 이 패키지의 메타데이터를 YouTube Studio에 그대로 복사

영상 렌더링(TTS·ffmpeg)도 현재 컨테이너에 ffmpeg / edge-tts / CJK 폰트가 없어 실행 불가입니다.
필요하시면 렌더링 스크립트까지 추가로 작성해 드리겠습니다.
