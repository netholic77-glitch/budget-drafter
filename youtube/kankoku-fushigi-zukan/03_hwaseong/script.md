## 나레이션 통짜 원고 (TTS 입력용)

```
ソウルから1時間。歩ける世界遺産があります。
水原華城(スウォンファソン)。
1794年1月に着工し、1796年9月に完成しました。
わずか2年8か月。正祖(チョンジョ)王が築いた城です。
設計を支えたのは、実学者の丁若鏞(チョン・ヤギョン)。
西洋の技術書を参考に、石を吊り上げる「挙重機」を作りました。
40斤の力で、2万5千斤の石を持ち上げたと記録されています。
城壁は全長5.74キロ。長安門から訪花隨柳亭まで、実際に歩けます。
工事の記録『華城城役儀軌』が残り、費用も職人の名前も書かれていました。
だから失われた施設も、元どおりに復元できたのです。
1997年、ユネスコ世界遺産。
```

## 제작 노트

- **"2년 8개월"의 근거**: 수원문화재단 공식 소개가 1794년 1월 착공 / 1796년 9월 완공으로 적고 있어 32개월 = 2년 8개월입니다.
  시중 자료에는 "2년 9개월"도 흔한데, 이는 『화성성역의궤』가 기록한 공사 종료(1796년 8월)와 준공 낙성연(9월) 중
  어느 쪽을 끝으로 보느냐의 차이입니다. **영상에는 착공·완공 연월을 직접 말하고 개월 수는 보조로만 쓰는 편이 안전합니다.**
- **거중기 표기**: 정약용이 참고한 서양 역학서는 『기기도설(奇器圖說)』입니다. 『기중도설』로 잘못 적힌 자료가 많으니 주의하세요.
- **방화수류정(訪花隨柳亭)** 일본어 읽기는 `パンファスリュジョン`. 자막에는 한자 + 가타카나를 병기하세요.
- 화성행궁 관람은 09:00–18:00(매표 17:00 마감). 2026년 야간개장은 5/1~11/1 금~일·공휴일 18:00–21:30(입장마감 21:00),
  성인 2,000원입니다. 성벽 보행로 자체는 상시 개방 구간이 있으나 **행궁·시설은 별도 요금**이라는 점을 설명문에 명시했습니다.
