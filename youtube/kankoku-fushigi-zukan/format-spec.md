# 포맷 규격 — 종이인형 × 실사

## 화면 구성 (1080 × 1920, 30fps)

```
┌─────────────────────┐
│  ① 텍스트 레이어      │  일본어 고딕, 상단 1/4. 숫자는 한 단계 크게
│                     │
│  ② 실사 배경         │  공공누리 제1유형 사진 / 국가유산 3D 에셋
│     (켄번즈 미세 줌)   │  채도 -8%, 대비 +5% → 종이인형이 떠 보이게
│                     │
│  ③ 종이인형          │  화면 높이의 25~35%, 하단 1/3에 배치
│     (드롭섀도우)      │  ※ 이 레이어가 없는 컷은 업로드 금지
└─────────────────────┘
```

### 종이인형 캐릭터 「ハンちゃん」

- **분절**: 머리 / 몸통 / 팔 2개 / 다리 2개 — 6피스 컷아웃. 종이 질감 텍스처 + 가장자리 살짝 거칠게.
- **의상**: 기본 한복(적·청). 사찰 편은 갓, 성곽 편은 도포 등 편마다 소품만 교체 → 제작비 0, 식별성 유지.
- **움직임**: 관절 회전만 사용. 트위닝 금지 — **종이가 툭툭 꺾이는 2~3프레임 스냅**이 이 채널의 시그니처다.
- **역할**: 손으로 가리키기 → 놀라기 → 걸어서 화면 이동. 말은 하지 않는다(나레이션이 대신).
- **그림자**: 실사 위에 `opacity 25% / blur 8px / y+12px` 고정. 이게 "종이가 사진 위에 얹힌" 느낌의 전부다.

### 실사 배경 처리

- 한 컷당 **켄번즈 1.0 → 1.06 미세 줌** (60초에 8~11컷).
- 컷 전환은 **하드컷**. 디졸브·와이프 쓰지 않는다. 종이의 툭툭 끊기는 리듬과 맞춘다.
- 사진 하단 오른쪽에 8pt 출처 워터마크 상시 노출 (`ⓒ한국관광공사 사진갤러리-촬영자` 등).

## 60초 구조 (고정 템플릿)

| 타임 | 구간 | 내용 | 종이인형 동작 |
|---|---|---|---|
| 0–3초 | **후크** | 숫자 하나 또는 반전 사실 한 줄 | 화면 밖에서 툭 들어와 가리킴 |
| 3–10초 | **장소 확정** | 일본어 명칭 + 한글 읽기 + 서울/부산에서 소요시간 | 지도 위에 착지 |
| 10–40초 | **볼거리 2~3개** | 하나당 8~12초. 각각 "왜 봐야 하는지" 한 문장 | 지점마다 이동, 놀라는 포즈 |
| 40–52초 | **실무정보** | 요금 · 운영시간 · 휴무일 · 예약 필요 여부 | 표지판을 들고 서 있음 |
| 52–60초 | **다음 편** | 다음 장소 0.5초 플래시 + 구독 | 손 흔들며 퇴장 |

**철칙:** 40~52초 실무정보 구간은 절대 생략하지 않는다. 재방문자가 이 채널을 구독하는 이유가 여기다.
