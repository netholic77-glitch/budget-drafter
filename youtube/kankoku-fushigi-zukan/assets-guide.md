# 저작권 안전한 영상·사진 소재 확보 가이드

유튜브 수익창출을 전제로 하므로, **"영리 이용 가능"이 명시된 소재만** 씁니다.
개인 블로그·핀터레스트·구글 이미지 검색 결과는 절대 사용하지 마세요.

## 1순위 — 공공누리 (kogl.or.kr)

공공기관이 개방한 저작물 포털입니다. **유형 표시를 반드시 확인**하세요.

| 유형 | 조건 | 이 채널 사용 가능? |
|---|---|---|
| 제1유형 | 출처표시 | ✅ **영리 목적 이용 가능** |
| 제2유형 | 출처표시 + 상업적 이용 금지 | ❌ 수익창출 채널에는 부적합 |
| 제3유형 | 출처표시 + 변경 금지 | ⚠️ 편집·자막 삽입 시 문제 |
| 제4유형 | 출처표시 + 비상업 + 변경금지 | ❌ |

한국관광공사 보유 저작물은 공공누리 **제1유형(출처표시)** 로 개방되어 있어 영리 목적 이용이 가능하고 출처만 표시하면 됩니다.

- 공공누리 https://www.kogl.or.kr/

## 2순위 — 국가유산 디지털 서비스 (digital.khs.go.kr)

국가유산청이 운영합니다. 유산 이미지뿐 아니라 **3D 에셋을 게임·영화·시뮬레이션 등
콘텐츠 제작자에게 무료로 제공**합니다. 다보탑·성곽 같은 구조물을 회전 렌더로 보여줄 때 유용합니다.

- https://digital.khs.go.kr/

## 3순위 — 한국관광공사 포토코리아 / 사진갤러리

- 포토코리아 https://phoko.visitkorea.or.kr/
- 사진갤러리 https://korean1.visitkorea.or.kr/kor/nphotogallery/photo.kto

**주의 (공사 이용약관 기준)**
- 사진갤러리 이미지는 **신청한 사용용도에 한정된 1회 대여용**입니다. 영상 1편마다 용도를 명시해 신청하세요.
- 공공누리 마크가 붙은 사진은 해당 유형 조건을 따르고, **마크가 없는 사진은 공사 담당자에게 이용 범위를 확인**해야 합니다.
- 모든 이용자는 `ⓒ한국관광공사 사진갤러리-촬영자` 형식으로 저작권을 표기해야 합니다.

## 직접 촬영이 가장 안전합니다

경복궁·불국사·수원화성 모두 개인 촬영은 자유입니다. 다만 아래는 별도 허가 대상입니다.
- 삼각대·짐벌을 이용한 상업적 촬영, 드론 촬영
- 궁·능 내 상업 촬영은 **궁능유적본부 사전 신청** 필요 (https://royal.khs.go.kr/)

## 음악·효과음

YouTube 스튜디오 > **오디오 보관함**(저작권 표시 필요 없음 필터)만 사용하세요.
외부 무료 사이트는 나중에 Content ID 클레임이 걸리는 사례가 잦습니다.
