# 채널 리브랜딩 설계서

> **개정 이력** — 초안의 `韓国、1分旅`(60초 정보형)에서 **`韓国ふしぎ図鑑`(70초 스토리형)** 으로 전면 교체했습니다.
> 사유는 §0에 적었습니다.

## 0. 왜 이름을 바꿨나

포맷이 「60초 정보 나열」에서 **「70초 반전 스토리」**(@weirdecon 계열)로 바뀌었습니다. 그러면서 기존 이름의 약점이 바로 드러났습니다.

| 문제 | 「韓国、1分旅」 | 「韓国ふしぎ図鑑」 |
|---|---|---|
| **길이를 이름에 박아 놓음** | 실제 완성본이 71.5초. 이름이 곧 거짓이 됨 | 길이와 무관 |
| **클릭 이유가 없음** | "1분 여행" — 무엇이 나올지 예측 가능 | **ふしぎ**(이상하다)가 반전을 예고 = 클릭 이유 |
| **소재가 금방 마름** | 「旅」는 관광지로 한정 | 「図鑑」은 장소·사물·관습까지 수집 대상 |
| **시리즈성** | 1편이 독립적 | **図鑑 = 모으는 것**. 다음 편을 보게 만듦 |
| **형제 브랜드** | 무관 | @weirdecon 과 한 계열로 읽힘 |

**결정: `韓国ふしぎ図鑑` (かんこく ふしぎ ずかん)**

## 1. 채널명

| 구분 | 표기 | 읽기 |
|---|---|---|
| **채택** | **韓国ふしぎ図鑑** | かんこく ふしぎ ずかん |
| 대안 A | 韓国ふしぎ辞典 | かんこく ふしぎ じてん — 「辞典」은 말뜻 쪽. 장소에는 図鑑이 맞음 |
| 대안 B | ふしぎな韓国図鑑 | 어순만 다름. 「韓国」이 뒤로 밀려 검색에서 불리 |

> 표기 주의: `ふしぎ`를 한자 `不思議`로 쓰지 않습니다. 히라가나 쪽이 부드럽고, 모바일 썸네일에서 획이 뭉치지 않습니다.

## 4. 로고

`render-clay/brand.py` 의 `logo()` 가 생성합니다.

- **노란 둥근 얼굴 + 검은 갓(笠)**. @weirdecon 의 노란 얼굴과 형제로 읽히되, 갓 하나로 "한국"을 표시합니다.
- 갓 테두리에 금색 1px 림 — 네이비 배경에서 실루엣이 죽지 않게.
- 얼굴 `#FFCF29` / 갓·눈 `#1A1E30` / 갓 림 `#D6B042`

## 6. 전환 체크리스트

1. YouTube Studio → 채널 맞춤설정 → 기본정보에서 이름을 `韓国ふしぎ図鑑` 으로 변경
   - **주의: 14일 내 2회 제한.** 한 번에 확정하세요.
   - **주의: 채널명을 바꾸면 인증 배지가 삭제됩니다.**
2. 핸들을 `@kankoku_fushigi` 로 변경 (별도 제한)
3. 프로필 사진 = `logo()` 출력 PNG
4. 설명문 = §3 블록 붙여넣기
5. 기존 「술이술이 마술이」 영상은 비공개 처리 여부 결정 — 주제가 완전히 달라 재생목록에 남기면 추천 신호가 흐려집니다
6. 업로드 시 **「변경된 콘텐츠 또는 합성 콘텐츠 → 예」** 체크 (AI 음성 사용)
