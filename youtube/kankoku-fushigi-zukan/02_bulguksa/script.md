## 나레이션 통짜 원고 (TTS 입력용)

```
世界遺産なのに、拝観料はゼロウォン。
慶州(キョンジュ)の仏国寺(プルグクサ)。
西暦751年、新羅の金大城(キム・デソン)が建て始めました。
完成は774年。1300年前の石組みです。
大雄殿の前に、二つの石塔。左の釈迦塔は高さ8.2メートル。
飾りを削ぎ落とした、静かな均整の美。
右の多宝塔は10.4メートル。石を木組みのように積み上げた、他に例のない形です。
実はこれ、韓国の10ウォン硬貨のデザインです。
1995年、石窟庵とともにユネスコ世界遺産に登録。
そして2023年5月から、拝観料は無料になりました。
開門は朝9時、年中無休。
```
