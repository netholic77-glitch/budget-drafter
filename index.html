주요 기능

🔎

저조사업 스크리닝

집행률 엑셀에서 임계치 미만 사업을 자동 추출. 컬럼 자동 매핑 지원.

📑

다양한 입력 형식

PDF·HWPX·텍스트·엑셀까지. HWP는 변환 안내 + 복붙 우회.

🤖

Gemini 무료 AI 분석

사업개요·문제점·분석의견 3개 섹션 본문을 Gemini 무료 모델이 자동 초안 작성. 유료 API 미사용.

⚙️

규칙기반 오프라인 폴백

키가 없거나 호출이 실패하면 인터넷 없이 집행률·키워드 규칙으로 즉시 초안 생성.

📄

표준양식 docx

맑은고딕·표제·표 포함 Word 문서 자동 생성. 부서·작성일 자동 채움.

🔢

문제점 ↔ 분석의견 1:1

①②③ 번호를 매겨 문제점과 분석의견을 같은 번호끼리 1:1로 대응시켜 검토가 쉬움.

업무 흐름

  1. ① 저조사업 스크리닝 집행률·실집행률 엑셀(또는 샘플) 업로드 → 컬럼 자동 매핑 → 임계치 입력 → 저조사업 자동 추출 → 분석 대상 선택 시 ②로 자동 반영
  2. ② 자료 입력 사업설명서 PDF/HWPX/텍스트(HWP 본문 복붙) 입력 + 사업명·소관부서·회계연도
  3. ③ 보고서 생성 Gemini 무료 AI 또는 규칙기반으로 사업개요·문제점·분석의견 자동 초안 → 편집창에서 수정 → docx 다운로드

개발 진행 상황

✅ 완료 Phase 1 — 표준양식 docx 생성기 (사업개요·문제점·분석의견 + 원본 발췌)
✅ 완료 Phase 2 — 집행률 엑셀 업로드 + 저조사업 스크리닝 (컬럼 자동 매핑)
✅ 완료 Phase 3 — PDF·HWPX·텍스트 입력 파서 (HWP는 변환/복붙 안내)
✅ 완료 Phase 4 — 규칙기반 오프라인 엔진 (집행률 구간·실집행 격차·키워드 → 문제점/의견 1:1)
✅ 완료 Phase 5 — Gemini 무료 AI 엔진 (다중 모델 폴백 + 503 재시도, 실패 시 규칙기반 자동 전환)
✅ 완료 Phase 6 — 완전 무료화 (유료 API·외부 저장소 제거, 키 없이도 동작)
⬜ 향후 확장 — 1차/2차 분석 반복 워크플로 (집행부 회신자료 누적 검토)

실행 방법

설치 (최초 1회) — run.bat을 더블클릭하면 자동으로 진행됩니다.

1) 가상환경(.venv) 자동 생성
2) requirements.txt에서 의존성 자동 설치
3) Streamlit 서버 자동 실행
4) 브라우저가 http://localhost:8501 자동 오픈

Gemini 무료 키 설정 (AI 분석을 쓰려면)

1) .env.example을 .env로 복사
2) GEMINI_API_KEY=...
   (https://aistudio.google.com/app/apikey 에서 무료 발급)

💡 키가 없어도 규칙기반 오프라인 모드로 전체 기능이 동작합니다. (유료 API 미사용)

주의사항

  • ⚠️ HWP(.hwp) 직접 지원 안 됨 — 한컴오피스에서 [다른 이름으로 저장] → HWPX 형식으로 변환 후 업로드하거나, 본문 텍스트 복붙을 사용하세요.
  • ⚠️ 스캔본 PDF는 텍스트 추출이 안 됩니다. 텍스트 레이어가 있는 PDF만 지원 (OCR은 추후 지원 예정).
  • ⚠️ API 키는 절대 외부에 공유 금지. .env 파일을 Git 커밋·이메일 첨부 등으로 유출하지 마세요.
  • ⚠️ AI 초안은 검토용 참고자료입니다. 자료에 없는 사실이 포함됐을 수 있으므로 반드시 검토 후 사용.
