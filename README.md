# budget-drafter

예산분석지원 시스템 — 엑셀·PDF 예산 자료를 업로드하면 전년 대비 증감을 분석하고, 워드 보고서를 자동으로 생성합니다.

## 기능

- 엑셀(.xlsx, .xls, .csv) 예산 자료 업로드 → 항목/부서/금년도·전년도 예산액 자동 인식
- 어떤 열을 무엇으로 읽었는지 화면에 표시, 읽지 못한 칸은 경고로 안내
- 항목별 증감액·증감률 계산, 정렬 및 시각화
- 총예산/총증감/최대 증가·감소 항목 요약 카드
- PDF 예산 자료 텍스트 추출(표 형식이 아닌 문서 미리보기용)
- 워드(.docx) 분석 보고서 자동 생성
- 전체 데이터(JSON/CSV) + 보고서를 zip으로 일괄 다운로드
- 샘플 데이터로 바로 체험 가능

모든 처리는 브라우저에서 이루어지며, 업로드한 파일이 서버로 전송되지 않습니다.

## 열 인식 규칙

예산 자료마다 열 이름이 다르므로 다음 순서로 금년도·비교기준 열을 고릅니다.

1. **헤더에 연도가 둘 이상 있으면** 큰 연도를 금년도, 그다음을 비교 기준으로 씁니다.
   (`2027년예산` / `2026년예산` → 금년도 2027, 비교기준 2026)
   연도를 코드에 박아두지 않으므로 회계연도가 바뀌어도 그대로 동작합니다.
2. **연도가 없으면** `전년도`·`전년`·`작년`·`기정`·`당초`·`종전` 표지로 비교 기준 열을 먼저 확정하고,
   **남은 열에서** 금년도 열(`예산액`·`편성액`·`계상액`·`요구액`·`본예산`·`추경예산` …)을 고릅니다.
   비교 기준을 먼저 확정하므로 `전년도예산액` 이 `예산액` 으로 잘못 잡히지 않습니다.
3. `증감`·`증감률`·`대비`·`비율`·`비고`·`순위`·`코드` 등 파생·메타 열은 금액 열 후보에서 제외합니다.

인식 결과는 분석 화면 상단에 그대로 표시되므로, 잘못 잡힌 경우 바로 확인할 수 있습니다.

## 금액 표기 해석

- 쉼표·`원`·`₩`·공백·전각 숫자를 정리해 읽습니다. (`1,234,000원` → `1234000`)
- **`△` 는 음수로 읽습니다.** 대한민국 정부 재정 문서는 마이너스를 `△` 로 적는 것이 관례이며,
  증가에는 표지를 붙이지 않습니다. 아래를 향한 `▽`·`▼` 도 감소로 읽습니다.
- **`▲` 는 부호를 뒤집지 않습니다.** 자료에 따라 증가 표지로 쓰이는 경우가 많아,
  임의로 음수 처리하면 조용히 틀린 값이 됩니다. 표지만 떼어내고 크기는 그대로 둡니다.
- 회계 괄호 표기 `(1,234)` 도 음수로 읽습니다.
- 숫자로 읽을 수 없는 칸은 0으로 처리하되, **몇 칸이 그렇게 처리됐는지 화면에 경고로 남깁니다.**

## 내려받는 CSV

`items.csv` 는 엑셀에서 바로 열 수 있도록 UTF-8 BOM + CRLF 로 씁니다.
항목명에 쉼표·따옴표·줄바꿈이 있어도 열이 밀리지 않으며,
`=`·`+`·`-`·`@` 로 시작하는 텍스트는 엑셀이 수식으로 실행하지 않도록 무력화합니다.
(금액 칸은 숫자로 쓰므로 음수는 그대로 유지됩니다.)

## 개발

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) 에서 확인할 수 있습니다.

### 테스트

```bash
npm test
```

의존성 없이 Node 내장 테스트 러너(`node --test`)를 씁니다.
열 인식·금액 해석·CSV 직렬화의 회귀 테스트가 `test/` 에 있습니다.

## 배포

`main` 브랜치에 푸시되면 GitHub Actions가 테스트(`npm test`) → 정적 빌드(`next build`, `output: export`) 후
GitHub Pages로 자동 배포합니다. 테스트가 실패하면 배포되지 않습니다.
